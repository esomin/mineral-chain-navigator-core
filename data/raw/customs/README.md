# 관세청(Customs) 수출입 실적 원시 데이터 디렉토리

본 디렉토리는 대한민국 관세청(Korea Customs Service) 수출입무역통계 포털(`tradedata.go.kr`)에서 수집한 핵심 광물 품목별·국가별 통관 실적 원시 파일(Raw Data)을 보관하는 곳입니다.

## 현재 보관 데이터: `customs_trade_2026.csv`

- **데이터 출처**: 관세청 수출입무역통계 (`tradedata.go.kr`) - 품목별 국가별 수출입 실적
- **기준 기간**: `2026년`
- **통계 기준**: 수리일 (통관 정식 수리 기준)
- **중량 단위**: 톤 (TON)
- **통합 수록 품목 (HSK 10자리)**:
  1. `2825.20-2000`: 수산화리튬 (Lithium Hydroxide)
  2. `2836.91-0000`: 탄산리튬 (Lithium Carbonate)
  3. `2825.90-2050`: 니켈 코발트 망간 수산화물 (NCM 전구체)
  4. `2504.10-1000`: 인상(鱗狀)흑연 (Natural Flake Graphite)

## 컬럼 스키마 구조

```csv
기간, 국가, HS코드, 품목명, 수출 중량, 수출 금액, 수입 중량, 수입 금액, 무역수지
```

## 파이프라인(ETL) 활용 방식

1. **원시 로그 적재 (`hsk_import_logs`)**:
   - 파일 내 각 국가별 통관 실적 행(Row)을 PostgreSQL DB에 그대로 보존합니다.
2. **LCE / MT 표준 단위 환산**:
   - Spec 1의 도메인 유틸리티(`convertHskToStandardVolume`)를 거쳐 수산화리튬 0.88 계수 등을 자동 적용합니다.
3. **핵심국가 Whitelist & 비례 재정규화 (Rescaling)**:
   - 중국(CN), 칠레(CL), 호주(AU) 등 주요국을 선별하고, 미세 잔여국을 비례 재조정하여 `sum(baselineShare) == 1.0000`인 엣지 가중치를 도출합니다.
4. **그래프 엣지 갱신 (`edges`)**:
   - 산출된 최신 가중치와 물동량을 `basePeriod: '2026'`으로 엣지 테이블에 반영합니다.
